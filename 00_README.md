## Evidence scale (A–E)

| Grade | Meaning |
|-------|---------|
| **A** | Strong — multiple quality trials and/or clinical guidelines supporting the protocol or its core package |
| **B** | Moderate — good studies/reviews support benefit; limitations remain (sample, heterogeneity, or indirectness) |
| **C** | Preliminary / mixed — promising or mixed findings; small trials, package-level evidence only, or large practice–evidence gaps |
| **D** | Traditional / experiential — longstanding practice with limited rigorous science; label clearly |
| **E** | Unsupported — popular claim not supported by evidence (see `14_UNSUPPORTED_CLAIMS.md`) |

**Rules of interpretation**
- Package evidence ≠ micro-skill evidence (e.g., DBT package ≠ isolated TIPP RCT).
- Correlation ≠ causation; remote/self-report trials can inflate effects.
- Traditional mechanisms (nadis, manifestation metaphysics) are labeled non-scientific when mentioned.
- Conflicting evidence is noted in protocol records and comparisons.

## Required protocol record schema

Every protocol uses exactly:

- Protocol name  
- Primary purpose  
- Problem it targets  
- Typical duration  
- Minimum useful duration  
- Step-by-step instructions  
- When to use it  
- Expected short-term effect  
- Expected longer-term effect  
- Mechanism / proposed mechanism  
- Evidence level (A/B/C/D/E)  
- Best supporting research  
- Potential risks  
- Who should avoid or modify it  
- Source links  
- Original creator/developer, if known

## How to use (founder / product)

1. Start with **problem → time available** in `09_TIME_BUCKETS.md`.  
2. Read the full record in `01_MASTER_DATABASE.md` (or category file).  
3. Check **Evidence level**, **risks**, and **avoid** before productizing.  
4. Prefer **A/B** protocols for default recommendations; keep **C/D** as optional/experimental with honest labels.  
5. Never market **E**-tier supernatural claims as science.  
6. For clinical insomnia components (stimulus control / sleep restriction), require clinician-guidance framing.

Breathing: physiological/cyclic sigh, box, coherent/resonance (~6 bpm), diaphragmatic, 4-7-8, alternate nostril, Lehrer-style paced/HRVB, Balban/Huberman 2023 cyclic sighing (verified).
