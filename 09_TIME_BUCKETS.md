# 09 — Time Buckets

Curated picks by available time / situation. Evidence grades in parentheses. Prefer higher grades when ties.

**Not medical advice.**

---

## 2 minutes

| Pick | Why |
|------|-----|
| Acute Physiological Sigh (B) | Fastest studied-family downshift; discreet |
| Affect Labeling (B) | Immediate cognitive-affect brake |
| 5-4-3-2-1 Grounding (C) | When breath focus worsens panic |
| Brief PMR hands-shoulders-face (B) | Somatic brace release |
| Cold Face Stimulation (C) | Peak arousal / TIPP Temperature |
| Cognitive Defusion one-liner (C) | Unstick fused thought quickly |
| Task-Switching Buffer (C) | Between meetings |

**Default stack (2 min):** Label emotion → 1–3 physiological sighs → one next action.

## Bad-sleep recovery (toolkit)

**Same night / next day (non-clinical first aid):**
1. Fixed wake time + morning outdoor light (A/B)
2. Caffeine cutoff (B)
3. Evening dim light (B)
4. Wind-down 30–60 min (C)
5. Cyclic sighing or PMR in chair (not clock-watching in bed) (B)
6. Short Yoga Nidra/NSDR as rest—**not sleep replacement** (C)
7. Brief early nap only if it will not destroy night sleep (B); avoid if chronic insomnia under stimulus control

**Chronic insomnia (product must say clinician):** Stimulus control (A) ± sleep restriction (A) inside CBT-I; do not DIY aggressive restriction.

## Perform-in-15-minutes

1. Morning light if morning performance (A) — or skip if already lit
2. 2–3 min cyclic sighing or tactical breath reset (B/C)
3. Centering + process cue (C)
4. 5–8 min PETTLEP imagery of first actions (B)
5. Pre-performance routine locked (B)
6. One if–then for the top obstacle (A)

---

## Mind-won't-stop

1. Affect label (B) + postpone worry to a slot (B)
2. 5-4-3-2-1 if spiraling (C)
3. Exhale-emphasized or resonance breathing 5–10 min (B)
4. Self-distancing or cognitive reappraisal (B/A)
5. Cognitive defusion if fused with thought content (C)
6. Tiny BA step to break rumination loop (A)
7. Attention restoration break if fatigue-driven (C)
8. Body scan if body tension co-drives mind (B)

**Bedtime mind-racing:** Prefer stimulus control leave-bed rule (A) over more thinking in bed.

---

## Extremely stressed

1. Safety check first (if danger/self-harm risk → professional/emergency help)
2. TIPP / cold face if peak arousal (C)
3. Acute physiological sighs 1–3 (B)
4. 5-4-3-2-1 grounding (C)
5. Brief PMR (B)
6. Micro social connection to a safe person (B)
7. Then: one controllable next action (if–then)

Avoid cyclic hyperventilation when extremely stressed.
