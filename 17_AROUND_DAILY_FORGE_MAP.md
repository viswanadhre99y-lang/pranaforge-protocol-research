# Public blocks around Daily Forge (never inside)

**Purpose:** Map which **public, evidence-graded** protocols may wrap your proprietary Daily Forge — without putting asana lists, pranic steps, timing cues, or certification criteria into GitHub/app.

**Locked rule:** Concierge / GitHub = **protocol ID + display name only**. Real Daily Forge recipe stays in your private vault.

---

## Architecture (one glance)

```
[BEFORE] public state tools          ← arousal / attention / cueing
    ↓
[DAILY FORGE] private IP             ← your movement + energy + breath method
    ↓
[AFTER] public close tools           ← scores, reappraisal, tiny action, lifestyle rails
    ↓
[BETWEEN DAYS] public load tools     ← sleep, light, exercise, WOOP — not session IP
```

Staff console may show: `daily_forge` + optional public adjunct labels.  
Staff console must **never** show: minute-by-minute Forge recipe.

---

## Zone map

### Zone A — PRE-FORGE (0–5 min) · allowed wrappers

| Public block | Role next to Forge | Leak risk |
|--------------|--------------------|-----------|
| Affect labeling | Name state before start | None |
| Acute physiological sigh (1–3) | Downshift if spiked | None |
| Brief PMR hands-shoulders-face | If breath-averse | None |
| 5-4-3-2-1 grounding | If dissociated / spiraling | None |
| Centering / short tactical breath | Attention gate into Forge | Low (keep generic) |
| Pre-performance routine shell | Same open cues every time | Low — **do not** embed Forge steps inside PPR doc in repo |

**Do not put in Zone A:** full Yoga Nidra script as “warm-up,” hyperventilation caution protocols, clinical sleep restriction.

---

### Zone B — INSIDE DAILY FORGE · private only

| What lives here | Where it lives |
|-----------------|----------------|
| Your asana / movement sequence | Founder vault |
| Pranic / energy-method cues | Founder vault |
| Exact breath ratios *inside* the method (if proprietary) | Founder vault |
| Facilitator cert criteria for Forge | Founder vault / NDA pack |
| Emotional-load technique detail (Emotional Load Reset, Clarity, Stress-Field Clearing) | Founder vault — public **names** only in product |

**Public library must not** duplicate or “approximate” these as filler sequences.

App field: `protocol_id: daily_forge` (+ optional `variant: am_peak | pm_downshift` as **labels** you define privately).

---

### Zone C — POST-FORGE close (1–5 min) · allowed wrappers

| Public block | Role | Leak risk |
|--------------|------|-----------|
| Score capture (Energy / Sleep restorativeness / Clarity) | Your existing close — keep | None |
| Cognitive reappraisal (one prompt) | Optional if stuck story appears | None |
| One if–then for next hour | Lock behavior after session | None |
| Tiny BA step | If withdrawal/rumination | None |
| Process note (what cue worked) | Learning loop — no recipe dump | None |

**Optional Clarity Protocol:** public **name** as ID `clarity_protocol`; steps stay vault-only. Do not paste public “visualization scripts” as a fake Clarity substitute in-repo.

---

### Zone D — SAME DAY, NOT INSIDE SESSION

| Public block | When | Notes |
|--------------|------|-------|
| Resonance / coherent breathing 5–10 min | Separate training block | Complementary; not a Forge replacement |
| Full PMR / body scan | Evening or rest day | Don’t merge into Forge README |
| Yoga Nidra / NSDR | Rest block; **not sleep replacement** | Market as rest-without-sleep |
| Postpone-worry slot | Daytime rumination | Keeps Forge from becoming talk therapy |
| Micro social check-in | Isolation / travel | Lifestyle rail |

---

### Zone E — BETWEEN DAYS (capacity, not session)

| Public block | Why it supports Forge outcomes without owning IP |
|--------------|--------------------------------------------------|
| Morning outdoor light | Better sleep → better session readiness |
| Fixed wake + evening dim + caffeine cutoff | Same |
| Stimulus control / CBT-I framing | Insomnia rails; clinician for restriction |
| Moderate aerobic exercise | Chronic stress load |
| WOOP + if–then | Adherence to “show up for Forge” |
| Jet-lag light/melatonin timing (careful) | Travel principals — lifestyle, not Forge |

## Emotional-load shells (names vs recipes)

| Public product name (OK) | Repo/app | Vault |
|--------------------------|----------|-------|
| Emotional Load Reset | ID only | Full method |
| Clarity Protocol | ID only | Full method |
| Stress-Field Clearing | ID only | Week themes / cues |

Public library analogs (reappraisal, affect label, TIPP, defusion) may sit **around** those shells as **staff safety / crisis bridges** — never marketed as “the PranaForge emotional protocol.”

## Safe day stack (example)

1. **Morning:** outdoor light (public)  
2. **Pre:** label + 1–3 sighs (public)  
3. **Daily Forge** (private IP)  
4. **Close:** scores + one if–then (public wrapper)  
5. **Evening:** dim light + wind-down; optional NSDR in chair (public)  
6. **Weekly:** WOOP for adherence (public)

---

## Anti-patterns (IP leak / claims risk)

- Publishing “Daily Forge v0.x” with FILL asanas “for now” in GitHub  
- Letting Kitchen/Floor bots invent breath-hold sequences  
- Selling NSDR as “same as sleep after Forge”  
- Teaching TIPP/cold face as medical dive-reflex therapy  
- Putting Cert checklist technique answers in the concierge repo
