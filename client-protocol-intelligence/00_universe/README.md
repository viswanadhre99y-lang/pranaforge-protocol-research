## Medical / professional care disclaimer

Educational research only. Not diagnosis, psychotherapy, or treatment. Breath-hold, hyperventilation, cold, sleep-restriction, and trauma-adjacent practices can harm. People with cardiovascular/respiratory disease, pregnancy, bipolar spectrum, epilepsy, panic, PTSD, or safety-risk symptoms need qualified clinicians before intensive protocols. **CBT-I sleep restriction and stimulus control = clinician-guided framing only.** Crisis → emergency/local professional help.

Individual micro-skills do **not** replace organizational fixes for burnout (staffing, workload, culture). Evidence for individual burnout programs in physicians is typically small–moderate and complementary to system change.

## Evidence scale (A–E)

| Grade | Meaning |
|-------|---------|
| **A** | Strong — multiple quality trials and/or clinical guidelines |
| **B** | Moderate — good studies/reviews; limitations remain |
| **C** | Preliminary / mixed — small trials, package-level, or practice–evidence gaps |
| **D** | Traditional / experiential — limited rigorous science |
| **E** | Unsupported — do not sell as science |

## Specificity tags (required on every protocol row)

| Tag | Meaning |
|-----|---------|
| **Generic** | Works across adults; lightly contextualized here |
| **Profession-specific** | Studied or strongly adapted for this occupation |
| **Situation-specific** | Tied to a moment (pre-OR, post-rejection, closing day) |
| **Lifestyle-specific** | Tied to schedule/lifestyle pattern (travel week, on-call) |
| **High-value** | High ROI for this client given constraints + evidence |
| **White-space** | Need exists; thin occupation-specific evidence — product opportunity with honest labeling |

Tags may combine (e.g., `Profession-specific|High-value`).

## Protocol record schema (full)

Every protocol in `02_protocols_by_client/` uses:

- Protocol name  
- Primary purpose  
- Problem it targets  
- Typical duration / Minimum useful duration  
- Step-by-step instructions  
- When to use it  
- Expected short-term / longer-term effect  
- Mechanism / proposed mechanism  
- Evidence level (A–E)  
- Best supporting research  
- Potential risks / Who should avoid or modify  
- Source links  
- Original creator/developer (if known)  
- **Specificity tags**  
- **Maps to question #**  

Base building blocks live in parent library `../01_MASTER_DATABASE.md`. Cluster B adds **client framing + profession-specific literature**.
