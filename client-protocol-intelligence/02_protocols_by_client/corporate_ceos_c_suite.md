### C-Suite Jet-Lag Directional Light + Melatonin Timing (CDC/AASM-Aligned)

- **Protocol:** C-Suite Jet-Lag Directional Light + Melatonin Timing (CDC/AASM-Aligned)
- **Client type:** Corporate CEOs / C-suite
- **Specific situation:** Flights crossing ≥2–3 time zones with meetings on arrival
- **Problem:** Circadian misalignment → sleep, cognition, GI, mood hits (CDC: ~68% business travelers regularly affected)
- **When:** Pre-flight 2–3 days through destination days 1–4
- **Duration:** Multi-day plan
- **Frequency:** Per long-haul arc
- **Instructions:** 1) For trips <3 days: consider staying on home time (non-adaptation) if schedule allows (CDC/AASM). 2) Else shift sleep 30–60 min/day toward destination. 3) Use jet-lag calculator for light SEEK/AVOID windows (east = morning light / evening avoid; west opposite pattern). 4) Melatonin 0.5–1 mg timed per calculator — avoid >5 mg; wrong timing worsens misalignment (CDC Yellow Book 2026). 5) Hydrate; limit alcohol; short naps ≤20–30 min. 6) Physician for Rx hypnotics/stimulants — not DIY.
- **Immediate effect:** Faster alignment vs unguided travel
- **Longer-term:** Less cumulative circadian debt for frequent flyers
- **Mechanism:** Phase response curves for light & melatonin
- **Evidence:** A/B — CDC Yellow Book 2026 jet lag; AASM circadian practice parameters; Eastman light/melatonin research
- **Population studied:** Travelers / circadian patients; business traveler surveys
- **Limitations:** Individual chronotype varies; melatonin OTC quality variable
- **Contraindications:** Discuss melatonin with physician if meds/pregnancy/autoimmune concerns
- **Safety:** No long half-life sedatives for in-flight self-medication without clinician
- **Self-admin?:** Mostly; melatonin under clinician guidance preferred
- **Supervision?:** Travel medicine / physician for meds
- **Source:** https://www.cdc.gov/yellow-book/hcp/travel-air-sea/jet-lag-disorder.html ; AASM CRSD parameters
- **Creator:** CDC/AASM-aligned traveler protocol
- **Date:** 2026-09-19

### Earnings / Board Morning Activation Stack

- **Protocol:** Earnings / Board Morning Activation Stack
- **Client type:** C-suite
- **Specific situation:** Earnings call or full board day
- **Problem:** Need alertness without jitter + emotional steadiness
- **When:** Morning of event
- **Duration:** 25–45 min
- **Frequency:** Per event
- **Instructions:** Outdoor light 10–20 min → light movement 10–20 min → caffeine only after light if used → 3 physiological sighs → process imagery of opening 60s → if–then for tough Q. No new alcohol night before.
- **Immediate effect:** Alert, grounded start
- **Longer-term:** Repeatable event OS
- **Mechanism:** Circadian alerting; catecholamines from movement; arousal fine-tune
- **Evidence:** A/B components; package C
- **Population studied:** Sleep/circadian + sports PPR analogs
- **Limitations:** Not a substitute for rehearsal
- **Contraindications:** Cardiac symptoms with exercise → physician
- **Safety:** OK
- **Self-admin?:** With EA
- **Supervision?:** EA
- **Source:** Circadian light science; Balban sigh; PPR
- **Creator:** C-suite situation package
- **Date:** 2026-09-19

### Hotel-Room Wind-Down Card (Staff-Executable)

- **Protocol:** Hotel-Room Wind-Down Card (Staff-Executable)
- **Client type:** C-suite travelers
- **Specific situation:** Night before high-stakes morning in hotel
- **Problem:** Arousal + light/noise → poor sleep opportunity
- **When:** Arrival evening
- **Duration:** 20–35 min
- **Frequency:** Travel nights
- **Instructions:** Staff/EA: cool room, blackout, earplugs; screens dim; 8–12 min PMR or resonance breathing; caffeine cutoff already enforced; optional low-dose melatonin only if in jet-lag plan. No “catch-up email in bed.”
- **Immediate effect:** Improved sleep opportunity
- **Longer-term:** Travel nights less chaotic
- **Mechanism:** Sleep hygiene + relaxation + circadian
- **Evidence:** B/A components
- **Population studied:** Insomnia hygiene/relaxation; travelers
- **Limitations:** Hotel constraints
- **Contraindications:** Melatonin per physician
- **Safety:** OK
- **Self-admin?:** Staff-assisted
- **Supervision?:** EA
- **Source:** Sleep hygiene evidence (supportive adjunct); PMR; CDC jet lag tips
- **Creator:** Ops package
- **Date:** 2026-09-19

### Post-Crisis Leadership Downshift (Affect Label + Values + Sigh)

- **Protocol:** Post-Crisis Leadership Downshift (Affect Label + Values + Sigh)
- **Client type:** C-suite
- **Specific situation:** After major incident/PR/layoff decision day
- **Problem:** Sympathetic residue + moral load
- **When:** Same evening
- **Duration:** 12–20 min
- **Frequency:** As needed
- **Instructions:** Affect label feelings → 5 min values compass (what mattered in the decision) → 5 min cyclic sighing or paced breathing → schedule clinical support if trauma/depression signs. Not a therapy replacement.
- **Immediate effect:** Partial discharge
- **Longer-term:** Prevents numbing-only coping
- **Mechanism:** Affect labeling; ACT values; autonomic downshift
- **Evidence:** B/C
- **Population studied:** General psych skills; not crisis-CEO RCT
- **Limitations:** Moral injury may need professional care
- **Contraindications:** Acute psychiatric crisis → clinician
- **Safety:** Escalate appropriately
- **Self-admin?:** Yes
- **Supervision?:** Coach/clinician as needed
- **Source:** Lieberman affect labeling; ACT values; Balban
- **Creator:** Composite
- **Date:** 2026-09-19
