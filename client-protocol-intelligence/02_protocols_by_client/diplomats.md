## Sequencing rule
1. Install **lifestyle rails** (light, wake, caffeine, evening dim, alcohol restraint as relevant).  
2. Add **acute regulation** (sigh / PMR / affect label) for spikes.  
3. Add **performance wrappers** (PPR / process imagery / if–then) only when foundations hold.  
4. Use **NSDR** as deep rest — never as sleep replacement.  
5. Escalate **CBT-I components** (stimulus control / sleep restriction) with clinician framing when insomnia is clinical.

## Full protocol schema adaptations (client-specific)

### Full schema — Diplomat Landing Circadian Pack
**Protocol name:** Diplomat Landing Circadian Pack
**Primary purpose:** Accelerate usable alertness on local clock after long-haul.
**Problem it targets:** Jet-lag impairment before meetings.
**Typical duration:** First 48h structured
**Minimum useful duration:** Day-of landing essentials
**Step-by-step instructions:**
1. Determine east/west shift; prioritize timed outdoor light per chronobiology guides.
2. Strategic naps 10–20 min early local afternoon if needed.
3. Melatonin only with clinician/known personal protocol — careful timing; avoid >5 mg DIY.
4. Evening dim; caffeine cutoff.
5. Coherent breathing 10 min to lower landing arousal.
6. Never drive impaired; use mission transport.
**When to use it:** Post long-haul to post/summit.
**Expected short-term effect:** Better local-clock alignment.
**Expected longer-term effect:** Light A; melatonin B careful; naps B.
**Mechanism / proposed mechanism:** SCN entrainment + homeostat.
**Evidence level:** A/B
**Best supporting research:** AASM circadian; CDC Yellow Book jet lag; Frontiers Physiol 2019.
**Potential risks:** Wrong-timed light/melatonin worsens shift.
**Who should avoid or modify it:** Bipolar/pregnancy — clinician for light/melatonin.
**Source links:** AASM; DOI 10.3389/fphys.2019.00927
**Original creator/developer, if known:** Chronobiology field.
**Safety:** Discretion; alcohol not a sleep aid night 0.

### Full schema — Negotiation Micro-Reset
**Protocol name:** Negotiation Micro-Reset
**Primary purpose:** Restore cognitive control between sessions.
**Problem it targets:** Reactivity / self-control fatigue.
**Typical duration:** 60–120 seconds
**Minimum useful duration:** 30 seconds
**Step-by-step instructions:**
1. Leave table if protocol allows; else silent.
2. 1–2 physiological sighs eyes open.
3. Label emotion; recall interest-based aim.
4. Sip water; soften jaw/shoulders.
**When to use it:** Bilateral/multilateral rounds.
**Expected short-term effect:** Less reactive speech.
**Expected longer-term effect:** Applied C with B-grade components.
**Mechanism / proposed mechanism:** Exhale + labeling + goals.
**Evidence level:** C
**Best supporting research:** Balban; affect labeling; negotiation psych applied.
**Potential risks:** Walking out breaches protocol — know norms.
**Who should avoid or modify it:** Trauma activation — EAP.
**Source links:** PubMed 36630953.
**Original creator/developer, if known:** Applied.
**Safety:** No classified content; EAP for hardship posts.
