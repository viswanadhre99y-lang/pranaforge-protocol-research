### 1. Cyclic Sighing (Physiological Sigh Pattern)

| Field | Content |
|------|---------|
| **Protocol name** | Cyclic Sighing (Physiological Sigh Pattern) |
| **Primary purpose** | Rapidly reduce acute arousal via double-inhale + long exhale. |
| **Problem targeted** | Acute stress spike, elevated respiratory rate, pre-meeting nerves. |
| **Typical duration** | 5 min daily; 1–3 cycles acutely |
| **Minimum useful duration** | 1–3 sighs (~30–60 s) |
| **When to use** | Acute spikes, pre-call, end-of-day downshift. |
| **Short-term effect** | Often calmer affect and slower breathing within minutes. |
| **Longer-term effect** | 28-day RCT: daily cyclic sighing improved mood vs matched mindfulness; reduced resting respiratory rate (Balban 2023). |
| **Mechanism** | Physiological sigh recruits alveoli; prolonged exhale increases parasympathetic influence. |
| **Evidence (A–E)** | **B** |
| **Best supporting research** | Yilmaz Balban et al., Cell Rep Med 2023; PubMed 36630953. |
| **Risks** | Lightheadedness if overdone; mouth dryness. |
| **Avoid / modify** | Severe respiratory disease, recent thoracic surgery, panic with breath-focus — use gentler long exhales. |
| **Sources** | https://pubmed.ncbi.nlm.nih.gov/36630953/ |
| **Creator / developer** | Studied by Balban/Huberman/Spiegel et al. (Stanford). |
| **Specificity tags** | `Generic|High-value` |
| **Maps to Q#** | 4,17,18 |

**Step-by-step**
1. Sit/stand upright.
2. Inhale slowly through nose until mostly full.
3. Second shorter nasal inhale to fully inflate.
4. Exhale slowly/fully through mouth or nose.
5. Repeat 1–3 cycles acutely or ~5 min as daily dose.

### 2. Coherent / Resonance Frequency Breathing (~6 breaths/min)

| Field | Content |
|------|---------|
| **Protocol name** | Coherent / Resonance Frequency Breathing (~6 breaths/min) |
| **Primary purpose** | Train HRV/RSA near ~0.1 Hz for autonomic downshift. |
| **Problem targeted** | Chronic stress load, low HRV, need trainable daily practice. |
| **Typical duration** | 10–20 min; ~5.5–6 breaths/min |
| **Minimum useful duration** | 5 min comfortable slow breathing |
| **When to use** | Daily stress regulation; pre-sleep if not alerting. |
| **Short-term effect** | Increased HRV/RSA during practice; often calmer mood. |
| **Longer-term effect** | HRVB/resonance breathing: small–moderate benefits for stress/anxiety/BP in reviews. |
| **Mechanism** | Respiration–HR–baroreflex resonance maximizes RSA (Lehrer/Vaschillo). |
| **Evidence (A–E)** | **B** |
| **Best supporting research** | Lehrer & Gevirtz Front Psychol 2014; Steffen et al. 2017. |
| **Risks** | Overbreathing dizziness; rare anxiety with interoception. |
| **Avoid / modify** | Severe lung disease; acute panic if breath focus worsens — shorten or guide clinically. |
| **Sources** | https://pmc.ncbi.nlm.nih.gov/articles/PMC4104929/ |
| **Creator / developer** | Paul Lehrer, Evgeny Vaschillo et al. |
| **Specificity tags** | `Generic|High-value` |
| **Maps to Q#** | 3,10 |

**Step-by-step**
1. Sit upright; nasal breathe if comfortable.
2. Pace ~6/min (e.g., 5 s in / 5 s out) or personal resonance if biofeedback available.
3. Gentle depth — avoid overbreathing.
4. Optional pacer/HRV biofeedback.

### 3. Box Breathing (Square Breathing)

| Field | Content |
|------|---------|
| **Protocol name** | Box Breathing (Square Breathing) |
| **Primary purpose** | Stabilize attention/arousal with equal inhale–hold–exhale–hold. |
| **Problem targeted** | Performance anxiety, scattered attention under pressure. |
| **Typical duration** | 2–5 min (e.g., 4-4-4-4) |
| **Minimum useful duration** | ~1–2 min |
| **When to use** | Pre-performance, between tasks, tactical reset. |
| **Short-term effect** | Subjective calm and attentional anchoring. |
| **Longer-term effect** | Balban 2023: improved mood/anxiety similarly to other arms; not superior to cyclic sighing on primary outcomes. |
| **Mechanism** | Paced breathing + mild holds provide structure; equal counts are heuristic not optimized resonance. |
| **Evidence (A–E)** | **C** |
| **Best supporting research** | Comparator in Balban 2023; limited isolating RCTs for exact box pattern. |
| **Risks** | Hold discomfort; dizziness. |
| **Avoid / modify** | Pregnancy, uncontrolled HTN, panic with holds, severe asthma — remove holds. |
| **Sources** | https://pubmed.ncbi.nlm.nih.gov/36630953/ |
| **Creator / developer** | Popularized in tactical/performance settings; single inventor unclear. |
| **Specificity tags** | `Generic|Situation-specific` |
| **Maps to Q#** | 4,17 |

**Step-by-step**
1. Choose sustainable count (often 4 s).
2. Inhale nose → hold gently full → exhale → hold near-empty, equal counts.
3. Stop if dizzy; shorten/remove holds as needed.

|------|---------|

| **Primary purpose** | Reduce somatic tension via systematic tense–release. |
| **Problem targeted** | Muscle guarding, occupational tension, arousal that blocks sleep onset. |
| **Typical duration** | 10–20 min full; 3–5 min brief (hands-shoulders-face) |
| **Minimum useful duration** | 3 min brief PMR |
| **When to use** | Wind-down; tension after desk/standing work; pre-sleep if body tense. |
| **Short-term effect** | Reduced perceived muscle tension and anxiety for many. |
| **Longer-term effect** | Longstanding clinical evidence base for anxiety/insomnia adjunct (package-level). |
| **Mechanism** | Reduced muscle afferent drive; attentional shift; conditioned relaxation response. |
| **Evidence (A–E)** | **B** |
| **Best supporting research** | Jacobson lineage; modern RCTs support PMR for anxiety/sleep as adjunct. |
| **Risks** | Pain if over-tensile; avoid injured sites. |
| **Avoid / modify** | Acute injury, uncontrolled HTN for strong isometrics — use release-only cues. |
| **Sources** | Clinical PMR literature; see parent master library. |
| **Creator / developer** | Edmund Jacobson (original); abbreviated clinical adaptations widely used. |
| **Specificity tags** | `Generic|High-value` |
| **Maps to Q#** | 8,1 |

**Step-by-step**
1. Tense one muscle group ~5 s without pain, then release 10–15 s.
2. Progress feet→face (or reverse); notice contrast.
3. Brief version: fists, shoulders, jaw/face only.

### 5. Stimulus Control Therapy (CBT-I Component) — Clinician-Guided Framing

| Field | Content |
|------|---------|
| **Protocol name** | Stimulus Control Therapy (CBT-I Component) — Clinician-Guided Framing |
| **Primary purpose** | Rebuild bed–sleep association; reduce conditioned arousal in bed. |
| **Problem targeted** | Insomnia with bed associated with wakeful worry/work. |
| **Typical duration** | Ongoing nightly rules; clinician package often 4–8 weeks |
| **Minimum useful duration** | Consistent application of core rules for several nights (under guidance) |
| **When to use** | Chronic sleep-onset/maintenance insomnia with conditioned arousal. |
| **Short-term effect** | May reduce time awake in bed within days–weeks when followed. |
| **Longer-term effect** | Core A-tier CBT-I component in guidelines. |
| **Mechanism** | Classical conditioning: extinguish bed–wake association; consolidate sleep drive. |
| **Evidence (A–E)** | **A** |
| **Best supporting research** | CBT-I guideline literature; Bootzin stimulus control classic; AASM CBT-I recommendations. |
| **Risks** | Temporary sleepiness; frustration; unsafe if sleep-deprived driving. |
| **Avoid / modify** | Bipolar spectrum / seizure risk without clinician; shift workers need adapted plans; never DIY aggressive restriction. |
| **Sources** | AASM CBT-I guidance summaries; PubMed CBT-I reviews. |
| **Creator / developer** | Richard Bootzin (stimulus control); CBT-I packages (Morin, Espie lineages). |
| **Specificity tags** | `Generic|High-value` |
| **Maps to Q#** | 1,2 |

**Step-by-step**
1. Use bed only for sleep/sex (no work laptop in bed).
2. If unable to sleep after ~15–20 min quiet wakefulness, leave bed; return when sleepy.
3. Fixed wake time; avoid compensatory long lie-ins.
4. No clock-watching; dim light out of bed.
5. **Do not self-prescribe aggressive sleep restriction** — pair with clinician if restricting time-in-bed.
