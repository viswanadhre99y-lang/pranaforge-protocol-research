## Sequencing rule
1. Install **lifestyle rails** (light, wake, caffeine, evening dim, alcohol restraint as relevant).  
2. Add **acute regulation** (sigh / PMR / affect label) for spikes.  
3. Add **performance wrappers** (PPR / process imagery / if–then) only when foundations hold.  
4. Use **NSDR** as deep rest — never as sleep replacement.  
5. Escalate **CBT-I components** (stimulus control / sleep restriction) with clinician framing when insomnia is clinical.

## Full protocol schema adaptations (client-specific)

### Full schema — Public Resilience Attention Drill (MMFT/MBAT-Informed Themes)
**Protocol name:** Public Resilience Attention Drill (MMFT/MBAT-Informed Themes)
**Primary purpose:** Train attention/interoception tolerance using **public** mindfulness themes only.
**Problem it targets:** Attention degradation under load (training/garrison context).
**Typical duration:** 10–20 min practice
**Minimum useful duration:** 5 minutes
**Step-by-step instructions:**
1. Use public MBAT/MMFT-style curricula via authorized instructors when available.
2. Themes from public literature: concentration, body awareness, open monitoring — **without operational tactics**.
3. Daily short practice > rare long sits.
4. Pair with sleep opportunity protection.
5. Track irritability/sleep; escalate clinical scores.
**When to use it:** Pre-deployment / high-demand intervals (training context).
**Expected short-term effect:** Better stress-recovery markers in MMFT study; attention protection claims evolving.
**Expected longer-term effect:** Adjunct resilience capacity — not trauma treatment replacement.
**Mechanism / proposed mechanism:** Attention control + interoceptive tolerance.
**Evidence level:** B/C
**Best supporting research:** Johnson et al. 2014 PMC4458258; VA mindfulness PTSD summaries; MBAT public trials.
**Potential risks:** Agitation; dissociation.
**Who should avoid or modify it:** Active PTSD without clinician; psychosis; crisis.
**Source links:** https://pmc.ncbi.nlm.nih.gov/articles/PMC4458258/
**Original creator/developer, if known:** MMFT (public Jha/Stanley lineage); MBAT public.
**Safety / scope:** PUBLIC OSINT ONLY — no classified tactics. PTSD: adjunct not replacement for trauma-focused care. Suicidality → crisis/veteran lines.

### Full schema — After-Action Hyperarousal Downshift (Unclassified)
**Protocol name:** After-Action Hyperarousal Downshift (Unclassified)
**Primary purpose:** Downshift after training without alcohol-first culture.
**Problem it targets:** Post-ex wired state in garrison.
**Typical duration:** 10–15 minutes

**Evidence level:** B

**Potential risks:** Avoidance of needed debrief.
