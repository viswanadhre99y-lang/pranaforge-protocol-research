## Sequencing rule
1. Install **lifestyle rails** (light, wake, caffeine, evening dim, alcohol restraint as relevant).  
2. Add **acute regulation** (sigh / PMR / affect label) for spikes.  
3. Add **performance wrappers** (PPR / process imagery / if–then) only when foundations hold.  
4. Use **NSDR** as deep rest — never as sleep replacement.  
5. Escalate **CBT-I components** (stimulus control / sleep restriction) with clinician framing when insomnia is clinical.

## Full protocol schema adaptations (client-specific)

### Full schema — Pre-Show Musician/Dancer Regulation
**Protocol name:** Pre-Show Musician/Dancer Regulation
**Primary purpose:** Lower somatic anxiety while preserving activation for performance.
**Problem it targets:** MPA somatic/cognitive arousal.
**Typical duration:** 5–10 minutes pre-show
**Minimum useful duration:** 2 minutes
**Step-by-step instructions:**
1. Nasal diaphragmatic or ~6 bpm coherent 3–6 min (voice-safe; no aggressive holds).
2. Brief PMR shoulders/hands/face — or ankles/hips for dance.
3. PPR: instrument/stance set → breath → first phrase/step cue.
4. Cognitive: reappraisal “energy not danger” if it fits.
**When to use it:** Backstage pre-show; dress rehearsal.
**Expected short-term effect:** Lower anxiety; steadier start.
**Expected longer-term effect:** MPA reviews support CBT + breath/relax packages.
**Mechanism / proposed mechanism:** RSA + muscle discrimination + attention set.
**Evidence level:** B
**Best supporting research:** PMC11851691; performer anxiety metas; Lehrer HRVB.
**Potential risks:** Voice strain if overbreathe; dizziness.
**Who should avoid or modify it:** Acute laryngitis/injury — medical; ED thoughts — clinical path.
**Source links:** PMC11851691.
**Original creator/developer, if known:** Applied arts medicine + sport psych.
**Safety:** Protect voice; no body-shame; physio owns pain.

### Full schema — Rehearsal Exposure Ladder for Feared Passages
**Protocol name:** Rehearsal Exposure Ladder for Feared Passages
**Primary purpose:** Reduce avoidance that maintains MPA.
**Problem it targets:** Passage-specific terror.
**Typical duration:** 10–20 min blocks
**Minimum useful duration:** 5 minutes
**Step-by-step instructions:**
1. Build hierarchy of feared excerpts.
2. Start mid-low difficulty with coping breath + PPR.
3. Pair with process imagery.
4. If–then: If panic cue → exhale ×3 → next bar/step.
5. Progress only when SUDS tolerable; celebrate approach.
**When to use it:** Practice weeks — not only show night.
**Expected short-term effect:** Reduced avoidance; confidence.
**Expected longer-term effect:** Exposure/CBT principles A; arts packaging B.
**Mechanism / proposed mechanism:** Fear extinction + mastery.
**Evidence level:** A/B
**Best supporting research:** CBT MPA trials; exposure science.
**Potential risks:** Flooding too fast.
**Who should avoid or modify it:** Clinical panic/PTSD — therapist.
**Source links:** MPA CBT literature.
**Original creator/developer, if known:** CBT applied.
**Safety:** Not for trauma processing without clinician.
