## Sequencing rule
1. Install **lifestyle rails** (light, wake, caffeine, evening dim, alcohol restraint as relevant).  
2. Add **acute regulation** (sigh / PMR / affect label) for spikes.  
3. Add **performance wrappers** (PPR / process imagery / if–then) only when foundations hold.  
4. Use **NSDR** as deep rest — never as sleep replacement.  
5. Escalate **CBT-I components** (stimulus control / sleep restriction) with clinician framing when insomnia is clinical.

## Full protocol schema adaptations (client-specific)

### Full schema — Call-Room Centering Sequence
**Protocol name:** Call-Room Centering Sequence
**Primary purpose:** 30–90s composure shift in marshalling without losing activation.
**Problem it targets:** Crowded call-room arousal spillover.
**Typical duration:** 30–90 seconds
**Minimum useful duration:** 1 deliberate breath + cue
**Step-by-step instructions:**
1. Name intensity quietly.
2. External focal point (lane mark / board edge).
3. Diaphragmatic or tactical breath — no long holds if dizzy.
4. Process cue only (rhythm, first meter) — never “win gold” as cue.
5. Commit to first action.
**When to use it:** Call-room, tunnel, on-deck.
**Expected short-term effect:** Composure + process focus.
**Expected longer-term effect:** Applied within PPR packages; branded sequence evidence C.
**Mechanism / proposed mechanism:** Breath + attentional narrowing to controllable cues.
**Evidence level:** C
**Best supporting research:** Ravizza centering tradition; Rupprecht 2021 PPR adjacency.
**Potential risks:** Internal focus harming automatic skills; delay.
**Who should avoid or modify it:** Prefer external cues for closed skills; heat illness → medical.
**Source links:** Sport psych centering; Rupprecht 2021.
**Original creator/developer, if known:** Ken Ravizza tradition / applied synthesis.
**Safety (heat/cold/breath/trauma):** Heat illness medical first; no extreme breath+cold.

### Full schema — Games Village Sleep Protect Pack
**Protocol name:** Games Village Sleep Protect Pack
**Primary purpose:** Protect sleep opportunity amid noise, late dining, excitement.
**Problem it targets:** Village insomnia and circadian disruption.
**Typical duration:** Nightly wind-down 20–40 min
**Minimum useful duration:** 10 min wind-down + fixed wake
**Step-by-step instructions:**
1. Fixed wake aligned to compete schedule when feasible.
2. Caffeine cutoff relative to event.
3. Evening light hygiene; mask/earplugs as allowed.
4. Wind-down: dim + PMR or coherent breathing ~10 min.
5. Stimulus-control spirit; chronic cases → clinician CBT-I.
6. NSDR if sleepless — rest framing, not sleep replacement.
**When to use it:** Staging + Games period.
**Expected short-term effect:** Better sleep opportunity adherence.
**Expected longer-term effect:** CBT-I components A; wind-down C; light A.
**Mechanism / proposed mechanism:** Circadian + homeostatic + associative sleep conditioning.
**Evidence level:** A/B (components)
**Best supporting research:** AASM insomnia/circadian guidance; jet-lag reviews.
**Potential risks:** Aggressive DIY sleep restriction; melatonin misuse.
**Who should avoid or modify it:** Bipolar — light/melatonin with clinician; clinical insomnia → CBT-I.
**Source links:** AASM; Frontiers Physiol 2019 jet lag.
**Original creator/developer, if known:** Sleep medicine field synthesis.
**Safety:** NSDR ≠ sleep replacement; no mega-dose melatonin.
