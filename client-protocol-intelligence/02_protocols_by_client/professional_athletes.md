## Sequencing rule
1. Install **lifestyle rails** (light, wake, caffeine, evening dim, alcohol restraint as relevant).  
2. Add **acute regulation** (sigh / PMR / affect label) for spikes.  
3. Add **performance wrappers** (PPR / process imagery / if–then) only when foundations hold.  
4. Use **NSDR** as deep rest — never as sleep replacement.  
5. Escalate **CBT-I components** (stimulus control / sleep restriction) with clinician framing when insomnia is clinical.

## Full protocol schema adaptations (client-specific)

### Full schema — Pro Compete-Day PPR
**Protocol name:** Pro Compete-Day Pre-Performance Routine
**Primary purpose:** Stabilize attention and arousal with a fixed 30–90s sequence before execution.
**Problem it targets:** Variable warm-up attention; choking under pressure.
**Typical duration:** 30–90 seconds
**Minimum useful duration:** 15–30 seconds
**Step-by-step instructions:**
1. Define 3–5 identical steps (stance → 1–2 breaths → external focus cue → trigger word → go).
2. Prefer external focus for closed skills (target, seam, rim).
3. Size arousal tool: physiological sigh if too high; short tactical breath if need structure without heavy downshift.
4. Rehearse in practice until automatic; do not invent new steps on game day.
5. Simplify with sport psychologist if routine becomes compulsive.
**When to use it:** Immediately before self-paced/restartable skills; micro between plays.
**Expected short-term effect:** Reduced performance variability; clearer attentional set.
**Expected longer-term effect:** Sport psychology meta-analysis supports PPR benefits under pressure.
**Mechanism / proposed mechanism:** Attentional control; cue–response binding; arousal titration; motor preparation consistency.
**Evidence level:** B
**Best supporting research:** Rupprecht, Tran & Gröpel 2021 IRSEP meta-analysis (https://doi.org/10.1080/1750984X.2021.1944271).
**Potential risks:** Superstition/compulsion; over-length delaying play.
**Who should avoid or modify it:** OCD-spectrum rigidity — simplify. Not medical care. Concussion — medical first.
**Source links:** https://doi.org/10.1080/1750984X.2021.1944271
**Original creator/developer, if known:** Applied sport psychology field.
**Safety (heat/cold/breath/trauma):** No breath-holds in water/ice/driving; no hyperventilation+cold stacks; trauma history — prefer eyes-open external cues.

### Full schema — PETTLEP Skill Rehearsal (Pro)
**Protocol name:** PETTLEP Skill Rehearsal Block
**Primary purpose:** High-fidelity imagery matching Physical, Environment, Task, Timing, Learning, Emotion, Perspective.
**Problem it targets:** Travel without full practice; return-to-play mental reps.
**Typical duration:** 8–15 minutes
**Minimum useful duration:** 3–5 minutes high-quality
**Step-by-step instructions:**
1. Physical: stance/kit cues when possible.
2. Environment: venue detail or video.
3. Task at real-time speed; update as skill evolves.
4. Emotion manageable — not catastrophe loops.
5. Prefer first-person for motor skills; pair with physical practice when available.
**When to use it:** Travel days; pre-comp activation; rehab adjunct with clearance.
**Expected short-term effect:** Cue familiarity and readiness.
**Expected longer-term effect:** PETTLEP-informed MI supported in reviews, especially with physical practice.
**Mechanism / proposed mechanism:** Functional equivalence / overlapping motor networks.
**Evidence level:** B
**Best supporting research:** Holmes & Collins 2001; Appl Sci 2022 PETTLEP review https://doi.org/10.3390/app12199753 ; PMC12109254.
**Potential risks:** Anxiety amplification if failure-focused; replacing training.
**Who should avoid or modify it:** Active psychosis; trauma triggers without guidance; concussion per medical staff.
**Source links:** https://doi.org/10.3390/app12199753
**Original creator/developer, if known:** Holmes & Collins (PETTLEP).
**Safety (heat/cold/breath/trauma):** Stop if imagery triggers trauma; medical clearance post-concussion.
