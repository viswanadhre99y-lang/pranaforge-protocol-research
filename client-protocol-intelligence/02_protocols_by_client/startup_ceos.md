### Board-Week EA Cue Card Stack

- **Protocol:** Board-Week EA Cue Card Stack
- **Client type:** Startup CEOs
- **Specific situation:** 48h before through night after board
- **Problem:** Pre-board hyperarousal + post-board rumination
- **When:** Each board cycle
- **Duration:** Micro 2–8 min cues across days
- **Frequency:** Per board
- **Instructions:** EA runs cards: (1) Night-before: dim light; slide cutoff; optional resonance breathing ~6/min × 8 min. (2) Morning outdoor light + protein. (3) T-15: recognize–release (sigh)–refocus on first agenda aim (Ravizza-style centering). (4) After: 10 min postpone-worry log + walk; no binge alcohol.
- **Immediate effect:** Lower spike; cleaner close
- **Longer-term:** Board as trained performance
- **Mechanism:** PPR; paced breathing; rumination stimulus control
- **Evidence:** C package; components A/B (Lehrer HRV B; sigh B; centering C)
- **Population studied:** Sports PPR; breathing RCTs; not CEO RCT
- **Limitations:** Won’t fix weak board materials
- **Contraindications:** Avoid long breath-holds if contraindicated
- **Safety:** Standard breath safety
- **Self-admin?:** With EA
- **Supervision?:** EA/coach
- **Source:** Ravizza centering; Balban 2023; Lehrer & Gevirtz HRV
- **Creator:** Situation package for CEOs
- **Date:** 2026-09-19

### CEO Strategic Block + Soft-Fascination Break

- **Protocol:** CEO Strategic Block + Soft-Fascination Break
- **Client type:** Startup CEOs
- **Specific situation:** Calendar obesity killing strategy
- **Problem:** No cognitive altitude
- **When:** 2–4×/week protected
- **Duration:** 50–90 min + 5–10 min break
- **Frequency:** Weekly
- **Instructions:** EA shields block. Phone away. One strategic question. Break: distant trees/sky or silent walk (soft fascination). Capture ≤3 bullets.
- **Immediate effect:** Clearer priorities
- **Longer-term:** Less reactive leadership
- **Mechanism:** Attention Restoration Theory; reduced switch cost
- **Evidence:** C
- **Population studied:** Environmental psych ART; executive practice
- **Limitations:** Requires authority to protect time
- **Contraindications:** None
- **Safety:** OK
- **Self-admin?:** Needs EA
- **Supervision?:** No
- **Source:** Kaplan ART; task-switching research
- **Creator:** Practice adaptation
- **Date:** 2026-09-19

### All-Hands Pre-Performance Routine (Process Imagery)

- **Protocol:** All-Hands Pre-Performance Routine (Process Imagery)
- **Client type:** Startup CEOs
- **Specific situation:** All-hands / keynote
- **Problem:** Performance anxiety + outcome fantasy
- **When:** T-20 to T-5
- **Duration:** 8–12 min
- **Frequency:** Per talk
- **Instructions:** Brief PMR hands-shoulders-face → 3 sighs → PETTLEP-lite first minute (stance, first sentence, first slide). Avoid ovation-only fantasy.
- **Immediate effect:** Stable opening
- **Longer-term:** Reliable PPR
- **Mechanism:** Arousal regulation + specific priming
- **Evidence:** B/C sports psych analogs
- **Population studied:** Athletes; exec transfer not RCT-proven
- **Limitations:** Needs content mastery
- **Contraindications:** Keep PMR brief if body-scan aversive
- **Safety:** OK
- **Self-admin?:** Yes
- **Supervision?:** Optional
- **Source:** PPR / PETTLEP sports psychology literature
- **Creator:** Analog package
- **Date:** 2026-09-19

### Post-Board Postpone-Worry + Wind-Down

- **Protocol:** Post-Board Postpone-Worry + Wind-Down
- **Client type:** Startup CEOs
- **Specific situation:** Evening after contentious board
- **Problem:** Sleep-onset rumination
- **When:** Same night
- **Duration:** 15–25 min
- **Frequency:** As needed
- **Instructions:** 5 min worry list + schedule debrief tomorrow with coach/CoS → PMR/body scan 8–12 min → dim light, no Slack → if awake ~20 min leave bed.
- **Immediate effect:** Faster sleep onset for many
- **Longer-term:** Breaks board→insomnia link
- **Mechanism:** Worry postpone; relaxation; stimulus control
- **Evidence:** A/B components
- **Population studied:** Insomnia CBT; not CEO-specific
- **Limitations:** Alcohol undermines
- **Contraindications:** Chronic insomnia → full CBT-I
- **Safety:** OK
- **Self-admin?:** Yes
- **Supervision?:** If chronic
- **Source:** CBT-I components; PMR reviews
- **Creator:** Public CBT bundle
- **Date:** 2026-09-19
