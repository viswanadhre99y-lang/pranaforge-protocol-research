### Post-Client Emotional Labor Reset

- **Protocol:** Post-Client Emotional Labor Reset
- **Client type:** Wealth managers / private bankers
- **Specific situation:** After anxious/angry client meeting
- **Problem:** Absorbed affect; residual hyperarousal
- **When:** Immediately after
- **Duration:** 5–10 min
- **Frequency:** As needed
- **Instructions:** Affect label (“I absorbed their fear”) → 3 sighs or 4 min resonance breathing → write facts vs client emotion → if–then delay on reactive portfolio action unless true urgency → brief walk.
- **Immediate effect:** Less contagion-driven trading/comms
- **Longer-term:** Lower emotional exhaustion
- **Mechanism:** Contagion interrupt; autonomic; II
- **Evidence:** B/C — advisor stress surveys document load (e.g., CNBC/FPA coverage 2019); Arthur et al. 2025 JD-R scoping on advisers; protocol package C
- **Population studied:** Financial advisers burnout literature; tools from general psych
- **Limitations:** Thin RCTs of this exact reset in advisers
- **Contraindications:** None
- **Safety:** OK
- **Self-admin?:** Yes
- **Supervision?:** Peer supervision culture helps
- **Source:** https://journals.sagepub.com/doi/10.1177/03128962251350337 ; CNBC advisor stress reporting; Balban; affect labeling
- **Creator:** Profession packaging
- **Date:** 2026-09-19

### Market-Open Arousal Gate

- **Protocol:** Market-Open Arousal Gate
- **Client type:** Wealth managers
- **Specific situation:** Gap downs / crash mornings
- **Problem:** Sympathetic surge → poor first calls
- **When:** First 15 min after open on stress days
- **Duration:** 3–6 min before outbound calls
- **Frequency:** Volatile days
- **Instructions:** Before calling clients: 3 sighs + checklist (facts known / unknown / action) + one values cue (“fiduciary calm”). Caffeine after gate if needed.
- **Immediate effect:** Steadier first conversations
- **Longer-term:** Client trust under volatility
- **Mechanism:** Arousal gate + cognitive offload
- **Evidence:** C
- **Population studied:** Not adviser-specific RCT
- **Limitations:** Extreme crashes still hard
- **Contraindications:** None
- **Safety:** OK
- **Self-admin?:** Yes
- **Supervision?:** No
- **Source:** Balban; checklist discipline practice
- **Creator:** Situation package
- **Date:** 2026-09-19

### Advisor WhatsApp Boundary If–Then

- **Protocol:** Advisor WhatsApp Boundary If–Then
- **Client type:** Wealth managers
- **Specific situation:** Always-on UHNW clients
- **Problem:** Boundaryless availability → sleep & resentment
- **When:** Nights/weekends
- **Duration:** Rule set
- **Frequency:** Ongoing
- **Instructions:** Define SLA with clients (except true emergencies). If–then: after hours non-emergency → morning reply template. Team coverage rotation if firm allows. Pair with wind-down routine.
- **Immediate effect:** Fewer night arousals
- **Longer-term:** Burnout risk reduction
- **Mechanism:** Detachment; II
- **Evidence:** B/C occupational
- **Population studied:** Recovery research; adviser demand literature
- **Limitations:** UHNW expectations
- **Contraindications:** None
- **Safety:** OK
- **Self-admin?:** Needs firm support
- **Supervision?:** Manager
- **Source:** Sonnentag; adviser JD-R scoping 2025
- **Creator:** Adaptation
- **Date:** 2026-09-19

### Pre-Annual-Review Presence Routine

- **Protocol:** Pre-Annual-Review Presence Routine
- **Client type:** Wealth managers
- **Specific situation:** High-stakes annual review with UHNW
- **Problem:** Performance anxiety + anticipation of complaints
- **When:** T-15
- **Duration:** 8–12 min
- **Frequency:** Per review
- **Instructions:** PMR brief → sighs → process imagery of listening first → if–then for fee objection. Review numbers earlier — routine is regulation not prep.
- **Immediate effect:** Calmer presence
- **Longer-term:** PPR habit
- **Mechanism:** PPR
- **Evidence:** C
- **Population studied:** Sports analogs
- **Limitations:** Won’t fix poor performance results
- **Contraindications:** None
- **Safety:** OK
- **Self-admin?:** Yes
- **Supervision?:** No
- **Source:** PPR; PMR; Balban
- **Creator:** Adaptation
- **Date:** 2026-09-19
