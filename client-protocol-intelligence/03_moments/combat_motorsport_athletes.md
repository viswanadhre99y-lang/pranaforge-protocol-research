**Use:** Trigger → protocol posture map for personalization engines and staff cue cards.

| Moment | Protocol posture |
|--------|------------------|
| **Weigh-in / face-off** | Tactical breath + reappraisal + values — separate from medical cut |
| **Cage / corner / grid** | PPR + external focus (apex/hip/glove) — not hostile cue words |
| **Between rounds / stops** | 1–2 physiological sighs + next-action cue |
| **Post adrenaline dump** | Exhale pacing + PMR + wind-down + sleep rails |
| **Heat cockpit / humid venue** | Sports-med cooling first; gentle nasal breathing only |
| **Travel + media day** | Task buffers + sigh resets between media and training |

## Design notes
- Moments are **situational entry points**, not diagnoses.
- Prefer the shortest effective stack that matches available privacy and time.
- If safety risk / clinical crisis → professional help, not protocol theater.
