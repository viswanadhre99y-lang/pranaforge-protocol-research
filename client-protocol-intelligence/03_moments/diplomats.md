# Moments — Diplomats

> **Disclaimer:** Educational personalization intelligence for PranaForge research — **not medical advice**, not psychotherapy, not a treatment plan. Not PranaForge proprietary session IP. Prefer A/B public protocols as defaults; label C/D honestly; never market E-tier claims as science. **NSDR ≠ sleep replacement.** Melatonin: timed chronobiotic tool — not DIY mega-dosing.

**Slug:** `diplomats`  
**Use:** Trigger → protocol posture map for personalization engines and staff cue cards.

| Moment | Protocol posture |
|--------|------------------|
| **Land → meeting <12h** | Light timing + nap strategy + 10m coherent/sigh; mission transport if impaired |
| **Hard negotiation block** | Micro sigh + interest-based aim cue + ART break if protocol allows |
| **Protocol banquet late** | Earlier caffeine cutoff; exit strategies; wind-down after |
| **Crisis cable night** | Tactical breath + if–then triage; later shutdown — EAP if trauma |
| **Home leave re-entry** | BA tiny + social connection + sleep consistency |
| **Hardship tour steady week** | Daily coherent + exercise + worry postpone + EAP awareness |

## Design notes
- Moments are **situational entry points**, not diagnoses.
- Prefer the shortest effective stack that matches available privacy and time.
- If safety risk / clinical crisis → professional help, not protocol theater.
