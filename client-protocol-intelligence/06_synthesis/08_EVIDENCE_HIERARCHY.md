# 08 — EVIDENCE HIERARCHY (Synthesis Draft)

**Compiled:** 2026-09-19 (Asia/Calcutta)  
**Applies to:** Client-protocol personalization using public protocols only.

## Tier 0 — Safety gates (always first)

1. Crisis / self-harm / mania / psychosis / medical emergency → professional/emergency care.  
2. Safety-critical work (pilots, some clinical/industrial roles) → no drowsy-making or DIY sleep restriction.  
3. Pregnancy, uncontrolled CVD/respiratory disease, epilepsy, bipolar spectrum, panic with breath-hold aversion, trauma → modify or avoid intensive protocols; clinician.

## Tier 1 — Foundations (prefer A)

| Protocol family | Grade | Client relevance |
|-----------------|-------|------------------|
| Morning outdoor light / timed light | A | Nearly all; jet-lag & social jet lag critical |
| CBT-I stimulus control | A | Sleep recovery seekers; travel-triggered insomnia |
| CBT-I sleep restriction | A | Clinical insomnia ONLY — clinician-guided |
| Moderate aerobic exercise | A | Burnout, chronic stress, mood, performance floor |

## Hierarchy application algorithm

```
IF clinical insomnia → CBT-I path (Tier 1) + clinician
ELIF jet lag / schedule shift → timed light (± melatonin careful) (Tier 2)
ELIF burnout / anhedonia → BA + light + sleep opportunity + exercise (Tier 1)
ELIF acute arousal spike → sigh / PMR / affect label (Tier 2) ± TIPP if peak (Tier 3)
ELIF high-stakes performance → PPR + process imagery (Tier 2) AFTER foundations
ELIF attention fatigue → ART + buffers + shutdown (Tier 3) + sleep rails
ALWAYS → reject E-tier framing; NSDR ≠ sleep replacement
```

## Package vs micro-skill

DBT package ≠ isolated TIPP RCT. MBSR package ≠ isolated body scan. Sport imagery meta-analyses ≠ fantasy visualization. Label honestly in client copy.
