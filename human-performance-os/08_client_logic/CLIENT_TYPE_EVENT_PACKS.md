# Client-type event packs (priors)

These are **starting priors**, overwritten by individual learning.

## Founders
| Event | Default intervention family | Notes |
|-------|----------------------------|-------|
| Investor pitch T-30 | Pre-performance + process cue | No outcome fantasy |
| Post-failed pitch | Affect label + tiny BA + defer rumination | Not “manifestation” |
| Fundraising week | Sleep protect + meeting-gap resets | Load management |
| 16h day detected | Wind-down enforcement | Silence productivity nudges |
| Flight + pitch combo | Travel + pre-performance sequenced | |

## CEOs / C-suite
Board T-60; negotiation T-20; conflict aftermath; back-to-back; international board travel.

## Consultants
Client presentation; analytic marathon → cognitive offload; hotel decompression; red-eye.

## Investors / PE
Deal decision window; market-stress day (self-report); IC meeting; research binge → movement break.

## Athletes
Pre-comp PPR; post-comp decompress; travel/jet lag; high training load day → recovery priority (coord with medical staff).

## Physicians
Post-call sleep; emotional load after hard case (peer support > app); micro-reset between procedures if safe.

## Lawyers
Hearing T-30; discovery marathon; deadline night (caffeine/sleep hygiene).

## Creators / public figures
Pre-stage; post-social overload; irregular schedule → fixed wake priority.

## Frequent travelers
Pre-flight light plan; in-flight movement/sleep rules; arrival day light; no “NSDR replaces sleep.”

## UHNW / family-office principals
Prefer **staff-mediated** delivery; fewer pings; privacy maximal; calendar often via EA — integrate EA workflow.
