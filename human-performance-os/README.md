# Human Performance Operating System (HPOS) — Research Pack

**For:** Viswanadh Reddy / PranaForge  
**Date:** 2026-09-19  
**Status:** Research architecture (not product build yet)  
**Relation:** Complements `client-protocol-intelligence/` (who) and public protocol library (what). This pack is **when / whether / how to deliver**.

## What this is
A serious design for a **personal human-performance OS**: continuous client-state model → event detection → receptivity gate → protocol selection → personalized micro-message → feedback → learning — with privacy, safety, and honesty about measurement limits.

## What this is NOT
- Not a chatbot prompt kit  
- Not a medical device / diagnostic system  
- Not permission to invent PranaForge session IP  
- Not “AI that knows how you feel” from weak wearable signals
