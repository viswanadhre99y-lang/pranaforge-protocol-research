# Safety layer

## Principles
1. Wellness ≠ medicine; no diagnosis/treatment claims.  
2. Hard excludes beat ranking.  
3. Crisis → escalate, **not** protocol playbooks.  
4. Prefer false silence over false intervention.  
5. CBT-I **sleep restriction** = clinician-only.  
6. NSDR ≠ sleep replacement.  
7. No LoA / unsupported E-tier as science.

## Hard exclude matrix (examples)
| Client flag | Exclude examples |
|-------------|------------------|
| pregnancy | long breath holds (478, box long), hyperventilation, mega melatonin DIY |
| cardiovascular_disease | cold-face, TIPP temperature extremes, hyperventilation |
| panic_breath_intolerance | breath-focus protocols → prefer grounding |
| bipolar_spectrum | aggressive sleep restriction, unsupervised bright-light boxes |
| trauma_sensitive | long body-scan/yoga nidra without choice of seated/secular |
| high_risk_occupation + severe sleep debt | “performance hacks”; urge sleep opportunity / professional channels |
| epilepsy | hyperventilation, extreme breath holds |
| driving / sleeping | all pushes |

## Escalation
| Trigger | Action |
|---------|--------|
| Explicit crisis / self-harm language | Local emergency resources; consented human notify; stop protocol CTAs |
| Staff marks escalate | Lock auto-push; human only |
| Orthosomnia pattern | Reduce wearable-triggered messages |
| Eating-disorder-adjacent cold/exercise misuse | Block cold-face / compulsive exercise suggestions |

## When NOT to intervene
- Receptivity low  
- In meeting / driving / sleeping  
- Daily push cap hit  
- Need confidence very low and not user-pull  
- Ambiguous moral/political content  
- Client explicitly DND  
- Score < τ_select
