# MVP roadmap (V1→V5)

## V1 — Staff Top-3 Picker (**build first**)
**Inputs:** client_type, available_minutes, place_class, upcoming_event_tag, stress/energy 1–5, optional sleep_h.  
**Outputs:** top-3 protocol_ids + rationale codes + SILENCE + exclusions.  
**Channel:** staff console only.  
**Success:** staff acceptance rate; principal completion when delivered; decision logs.

## V2 — Calendar + silence policy
Ingest free/busy + next event stakes tags; receptivity gates; daily push caps still off or EA-only.

## V3 — Sleep duration + travel modules
Morning-light / jetlag cards; wind-down; caffeine policy; NSDR honesty copy. Wearable = duration/timing only.

## V4 — Outcome learning
Ratings + completion → personal response graph → adjust history/preference features.

## V5 — Cautious bandits / predictive
Bandits on safe set; optional receptivity model; MRT-style eval harness. Still hard safety gates.

## Explicitly later / research
Emotion-from-PPG; fully autonomous UHNW coach without human; deep RL; message-content surveillance.

## What becomes possible at each stage
| Stage | Possible |
|-------|----------|
| V1 | Explainable selection among 50; training staff; test-case automation |
| V2 | Moment detection pre-meeting / meeting-streak |
| V3 | Travel-circuit value prop |
| V4 | True personalization beyond CPI priors |
| V5 | Adaptive policy with audit trail |
